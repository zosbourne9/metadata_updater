================================================================================
APPLICATION FLOW
================================================================================

USER INTERACTION:
  1. User launches app → QApplication initializes → MetadataUpdater window created
  2. UIElements builds all widgets → Dark theme applied → Drag zone ready
  3. User drops files OR clicks "Select Files" → Files added to selected_files list
  4. User selects metadata fields → Toggles tracked in checkboxes
  5. User clicks "Update Tags" → on_update_tags() gathers selected fields
  6. start_update_thread() called → ProcessingThread created & started
  7. UI components disabled (except Reset button)

BACKGROUND PROCESSING:
  1. ProcessingThread.run() iterates through selected_files
  2. For each file:
     a. update_metadata() called (435+ lines of complex logic)
     b. Load audio file → Extract artist/title
     c. Check unified cache → Return if found
     d. Try MusicBrainz API → Get metadata
     e. Try Spotify API (if MB incomplete) → Get metadata
     f. Compare quality scores → Select best source
     g. Detect genres (MB artist → AI analysis if needed)
     h. Save to cache & write to audio file
     i. Emit progress signals
  3. For each file: progress, status, current_file signals emitted
  4. UI updates via connected signal handlers in real-time
  5. on_processing_finished() called → UI components re-enabled

SIGNAL FLOW:
  ProcessingThread.progress signal → progress_bar.setValue()
  ProcessingThread.status signal  → status_label.setText()
  ProcessingThread.current_file signal → current_file_label.setText()
  ProcessingThread.finished signal → on_processing_finished()
  ProcessingThread.error signal   → on_processing_error()

================================================================================
KEY TECHNICAL CHALLENGES & SOLUTIONS
================================================================================

CHALLENGE 1: Real-time Progress Updates
  Problem: Qt signals → real-time UI updates
  Solution Options:
    A) Polling: JS polls Python API every 100ms (simpler)
    B) WebSocket: Bi-directional real-time (better UX)
    C) Callbacks: Python calls JS directly (medium complexity)
  RECOMMENDATION: Polling for initial implementation

CHALLENGE 2: File Dialog Integration
  Problem: JS can't open OS file dialogs
  Solution:
    - Python API endpoints: select_files(), select_folder()
    - Use QFileDialog or tkinter.filedialog
    - Return file paths to JavaScript

CHALLENGE 3: Threading Coordination
  Problem: ProcessingThread must update UI safely
  Solution:
    - Keep ProcessingThread unchanged
    - Python method to get current progress state
    - JS polls this method
    - Thread-safe access via locks if needed

CHALLENGE 4: Modal Dialogs
  Problem: QMessageBox → native look & feel
  Solution:
    - HTML/CSS modal overlays
    - JavaScript event handling
    - Custom styling to match theme

CHALLENGE 5: Drag & Drop Overlay
  Problem: Qt overlay widget with custom painting
  Solution:
    - HTML5 Drag & Drop API
    - CSS for visual feedback
    - JavaScript dragover/dragleave handlers
